## Description
Ever crave your favourite restaurant dish but wince at the price tag? CopyCook was built to fix that! CopyCook is a recipe discovery platform where you can find copycat recipes from popular chain restaurants and see exactly how much you save by making it at home instead.



## Feature List
### Core Platform
- Recipe discovery (MealDB API, 4-col grid)
- Random Recipe Roulette
- Cook Along Mode
- Recipe detail page (ingredients + steps)
- Save to folders (public/private)
- Like system (Firestore subcollection)
- Comment drawer (real-time onSnapshot)
- Splash / landing page (index.html)
- Marketing pages: About, Contact
- Global 404 page
- Sign up, login, password reset
- Profile sync on sign-in
- Account popup (logout)
- Consistent sidebar navigation + notifications shell

### Social & Messaging
- Community posts (post.html)
- Individual post view with likes/comments
- Recipe ratings + “Made It!” button (Firestore counter for most-made recipes)
- Real-time 1:1 messaging
- Recipe sharing in chat
- Unread messages and notifications badge
- User profile navigation from chat
- Follow / following system (Firestore)
- Profile screen with stats + identity
- Saved hub + folder view
- Star ratings + recipe aggregates
- “Made It!” completion tracking
- Conversations list + thread UI

### AI & Explore
- Onboarding survey + personalized feed
- Leaflet.js grocery store map
- Explore page with restaurant grid
- Category pills + restaurant modal
- Static cost comparison tool
- Cuisine Passport (visual grid tracking cuisines cooked using strArea)
- Restaurant-style selector
- Voice search (Web Speech API)
- Chain restaurant catalog + featured/trending
- Search restaurants + MealDB recipe deep linking
- Category filters + personalized hero
- Copycat / community meal tie-ins
- Random recipe API integration

# Tech Stack
+ HTML, CSS and Javascript
+ Google Firebase Authentication
+ Google Firestore Database
+ TheMealDB API
+ Leaflet.js
+ OpenStreetMap
+ Overpass API
+ Web Speech API
+ Firebase Hosting (Live-Link)
